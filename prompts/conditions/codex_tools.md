You can read and edit files in this folder, and you can run Python with `.venv/bin/python` (numpy is installed; nothing else). Use it to check that build.py runs, that the shapes are right, and that each layer computes what you intended on inputs you construct by hand. Do not use it to fit or search for weights against labeled examples: if a check fails, fix your reasoning, not the numbers by trial and error. There is no network access.
